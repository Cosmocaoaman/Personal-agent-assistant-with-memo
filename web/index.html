    记忆召回 · Embedding API

    语义检索参数

    启用后后台建立并更新向量索引，仅新增或修改的事实需要重新生成。记忆文本与首次查询会发送到 Embedding 地址并产生 API 费用；重复查询可使用本次运行的缓存。网页搜索开关与此独立。模型、地址或维度改变后重新建立索引。接口不可用时仍可使用关键词检索。

    上下文与 Agent 执行上限

    记忆字符预算计量完整条目的 JSON，包含预载和该阶段工具读入的条目；近期对话、提示词、摘要和工具元数据另计。容量不足会省略完整条目，不切断事实，也不决定是否值得记忆。当前消息最多 12,000 字符；每次最多 8 项改动；回答与维护固定两个并行分支。

    主 Agent 与记忆子 Agent 使用同一模型、独立上下文，每轮会产生多次 API 调用。Key 以明文保存在本机数据库，重启后自动读取，聊天导出不包含 Key。推理会联网请求所选 API 地址。
